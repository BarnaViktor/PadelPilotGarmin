# Padel Pilot Privacy Notice

Last updated: 2026-08-20

Padel Pilot does not send personal data to the developer or to a developer-run
server. The application has no network communication permission and contains
no advertising, analytics or account system.

The application uses Garmin sensor and activity-recording APIs to create a
padel activity. Depending on the watch and the user’s settings, the activity
may include heart rate, calories, duration, point events and match results.
Active-match state and a history of up to 20 completed matches are stored
locally on the watch.

If the user synchronizes the watch, Garmin software may transfer the saved FIT
activity to Garmin Connect. That processing is controlled by Garmin and the
user’s Garmin account settings; it is not performed by the Padel Pilot
developer.

Users can discard an active or completed match before saving. Local
application data can be removed by uninstalling Padel Pilot. Activities already
synchronized to Garmin Connect must be deleted separately through Garmin’s
services.
