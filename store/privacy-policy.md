# Padel Pilot Privacy Notice

Last updated: 2026-09-05

Padel Pilot does not send personal data to the developer or to a developer-run
server. The application has no network communication permission and contains
no advertising, analytics or account system.

The application uses Garmin sensor and activity-recording APIs to create a
padel activity. Depending on the watch, granted permissions, available sensor
data and the user’s settings, the activity may include heart rate, calories,
duration, point events and match results. Starting a match also starts the FIT
activity and, when the user has granted Garmin's Positioning permission,
enables positioning so the saved activity may include location, GPS track,
distance and speed data.
Active-match state and a history of up to 20 completed or saved unfinished
matches are stored locally on the watch.

If the user synchronizes the watch, Garmin software may transfer the saved FIT
activity to Garmin Connect. That processing is controlled by Garmin and the
user’s Garmin account settings; it is not performed by the Padel Pilot
developer.

Users can discard an active or completed match before saving, and can delete
individual entries from the local match history. Deleting a history entry does
not delete its separately saved FIT activity. All local application data can be
removed by uninstalling Padel Pilot. Activities already synchronized to Garmin
Connect must be deleted separately through Garmin’s services.
