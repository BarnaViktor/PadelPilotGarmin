# Padel Pilot 1.2.0 assets

Current stable version: 1.2.0. Store screenshots use Forerunner 265, 416×416;
the release also supports the tested 416×416 AMOLED and 280×280 MIP profiles.
The unchanged icons contain no version or beta text and remain the app brand:
`padel-pilot-store-icon-500.png` (500×500) and
`padel-pilot-device-icon-128.png` (128×128).

All screenshots are fresh RGB/sRGB PNGs at 416×416. The display boundary is
masked to black; no desktop, simulator controls or personal data is included.
The home screenshot is from the production PRG. Remaining images are native
renders of the same final view/domain sources using sample match data under
a separate capture identity; they are not live-user match records.
